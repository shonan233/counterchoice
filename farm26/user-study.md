# Notes from User Study

* They generally like how the resulting melody sounds.
* Ability to hear the sounds as you enter
* Resetting with a button (as opposed to pressing F5)
* Exporting to another app 
* Current version does not encourage using contrary motion. Therefore, sometimes lots of parallel sixths, or parallel thirds are observed.
* Current version allows counterpoint notes to be selected below cantus firmus notes.
* Current version disallows cantus firmus to be entered in the above octave, but when hovered, it appears as if it is possible to click those notes.
* Discovering the shift-click functionality to enter counterpoint notes is not intuitive. Suggestions: 
  - Clicking on the same note the first time makes it cf, twice makes it cp, third deletes it.
  - There is a different symbol when hovered above the upper octave to indicate it is for counterpoint line.

* Having the ability to switch between sheet music and piano roll displays would be better.
* Note names are not displayed.
* Dusa implementation can be extended to allow intervals beyond an octave.
* Understanding the names in Dusa might be hard for people unfamiliar with counterpoint. (like "cf", "cpNote" etc.)
* Except for the cadence rule, other invalid inputs are not checked and a generic error message is displayed, which might mislead the users.
